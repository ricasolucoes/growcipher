# GrowCipher

GrowCipher é uma plataforma global, privada e offline-first para cultivadores de cannabis gerenciarem todo o ciclo de suas plantas com segurança, autonomia e controle total sobre os próprios dados.

## Documentação

Toda a documentação, escopo, requisitos e princípios do projeto estão estruturados como um cofre (Vault) do **Obsidian** na pasta `/docs`.

Para acessar as informações de projeto, abra a pasta `docs/` no aplicativo Obsidian e inicie a leitura pelo arquivo **`GrowCipher.md`**.

## Sobre o Projeto

* **Versão curta:** Um diário de cultivo mundial, offline e criptografado para produtores de cannabis. Registre plantas, ciclos, regas, alimentação, ambiente, materiais, custos e resultados com controle total sobre seus dados.
* **Pitch de uma frase:** O cofre digital do cultivador de cannabis: privado, offline, criptografado e sob controle exclusivo do usuário.
